# hazelcast-tornadovm-middleware
Навчальна комп'ютерна система для дослідження паралельних алгоритмів мовою Java. Проєкт реалізує концепцію трирівневого паралелізму: рівень кластера (Hazelcast), рівень процесора (пули потоків Hazelcast) та рівень GPU (TornadoVM).

Ця `middleware` система дозволяє розгортати обчислювальні задачі на гетерогенних фізичних кластерах (Hazelcast), використовуючи TornadoVM для динамічної компіляції Java-коду у ядра (Kernel) для виконання на відеокартах (через PTX/OpenCL) та синхронізуючи дані по локальній мережі.

**🧪 Тестовий алгоритм (Use Case):**
Для верифікації та демонстрації можливостей платформи в системі реалізовано алгоритм розподіленого навчання повнозв'язної нейронної мережі. Цей тестовий алгоритм розгортає обчислювальні графи на GPU, розподіляє сегменти датасету між вузлами та забезпечує фінальну агрегацію – збір локально навчених моделей з усіх робочих вузлів на головний клієнтський вузол (зберігаючи декілька незалежних моделей для подальшого створення ансамблю).

## ⚙️ Системні вимоги
* **ОС:** Windows 10 або Windows 11.
* **Java:** GraalVM CE 25.0.2 (JDK 25).
* **GPU:** NVIDIA (з підтримкою CUDA/PTX).
* **Фреймворк:** TornadoVM v4.0.0-jdk25.
* **Кластеризація:** Hazelcast v5.3.6.

## 🚀 Встановлення та ініціалізація

### 1. Клонування репозиторію
```bash
git clone https://github.com/HomerLund/hazelcast-tornadovm-middleware.git
```

### 2. Налаштування Java (GraalVM)
Відкрийте проєкт у вашому середовищі розробки (наприклад, IntelliJ IDEA). 
У налаштуваннях проєкту (Project Structure) обов'язково встановіть SDK на **GraalVM CE 25.0.2**. Всі необхідні залежності автоматично підтягнуться через Maven (`pom.xml`).

### 3. Налаштування TornadoVM
1. Завантажте скомпільований реліз `tornadovm-4.0.0-jdk25-full` з офіційного сайту.
2. Розпакуйте архів на локальний диск.
3. Додайте системні змінні середовища Windows:
   * `TORNADOVM_HOME` = `C:\Шлях\До\tornadovm-4.0.0-jdk25-full`
   * `JAVA_HOME` = `C:\Шлях\До\graalvm-ce-25.0.2`

### 4. Пошук індексу відеокарти
Для маршрутизації обчислень на правильний пристрій необхідно дізнатися його індекс. Відкрийте командний рядок (`cmd`) і виконайте:
```cmd
%TORNADOVM_HOME%\bin\tornado --devices
```
*Знайдіть у списку вашу дискретну відеокарту (наприклад, бекенд PTX) і запам'ятайте її індекс (зазвичай `1:0` або `0:0`).*

## 🛠 Запуск кластера

Система складається з двох основних компонентів: робочих вузлів (Worker Nodes) та клієнта-оркестратора (Menu).

### 1. Конфігурація робочого вузла (`RunWorkerNode.java`)
Для кожного комп'ютера в кластері створіть конфігурацію запуску (Run Configuration) у вашій IDE і **обов'язково** додайте такі `VM Options`:

```text
--module-path "%TORNADOVM_HOME%\share\java\tornado"
--add-modules tornado.api,tornado.runtime
-Djava.library.path="%TORNADOVM_HOME%\lib"
-Dtornado.device.default=1:0
```
*(Примітка: замініть `1:0` на індекс вашої відеокарти, отриманий на попередньому кроці).*

Запустіть `RunWorkerNode.java`. Вузол автоматично ініціалізує Hazelcast-інстанс і почне прослуховувати порт `5701`.

### 2. Запуск оркестратора (`RunMenu.java`)
Після того як усі робочі вузли кластера будуть запущені, виконайте клас `RunMenu.java` на головному комп'ютері. 
У консолі з'явиться меню управління системою, за допомогою якого ви зможете:
1. Ініціалізувати та розподілити RAM-кеші на всіх підключених вузлах.
2. Запустити процес розподіленого навчання нейронної мережі.
